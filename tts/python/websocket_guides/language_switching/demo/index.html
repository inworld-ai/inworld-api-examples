Language switching on one TTS context

A tutor turn marks the language being taught with <l2>…</l2>, with Japanese written in kana. One WebSocket client (language_switching.py) sends it four ways, and each card below is one of them: one flush, a flush per language, a flush per language opening with an instruction, and a stream the service cuts at sentence ends.

What decides what you hear

Kana decides Japanese

Most kanji have several readings, and the same characters read as Chinese. Kana has one reading and always reads as Japanese, so ask your LLM to write Japanese in kana. Chinese characters have several readings too (好, 还, 行, 长), and a Spanish word can be read as English: both are left to the voice and the prompt.

Detection picks one language per synthesis

The context sets no language, so the service detects one for every synthesis, by its script first:

  • Kana reads as Japanese; Hangul as Korean.
  • Chinese characters read as Chinese or Japanese; a word or two alone takes the language of the turn so far.
  • Latin letters go to a model, which needs a few words: a single Spanish word can read as English.

The prompt decides the accent

A voice with localized prompts speaks each flush on its prompt for the detected language, when per-language prompt switching is enabled for your workspace; otherwise every flush uses its own prompt. A voice cloned from a clip in both languages has one prompt with both accents, so no detection is needed for its accent.

The detected language also sets how numbers are read, and timestamps.

Instructions steer; sentence mode cuts

An inline instruction such as [in pure Spanish] at the start of a flush steers its delivery on whichever prompt the flush's detected language selects. Detection ignores the instruction, so it matters most where detection places a flush on the other language's prompt, as it does a single word. Instructions need inworld-tts-2.

In sentence-boundary auto mode the service starts a synthesis at every sentence end and detects its language. Sentences that arrive while one runs are batched, and a batch is spoken in one language.
